WindowDeck 0.3.0 añade **Duplicar pantalla principal**: transmite lo que muestra
Windows a la Steam Deck sin crear un monitor virtual ni instalar su driver.

El panel de Windows permite elegir el modo antes de pulsar Iniciar:

- **Extender escritorio**, predeterminado: crea la segunda pantalla para mover
  ventanas a la Deck. Conserva el funcionamiento anterior y requiere el driver.
- **Duplicar pantalla principal**: muestra la pantalla principal del PC y el
  cursor, ajustados a 1280 × 800 conservando la proporción. No cambia la
  configuración de pantallas de Windows. Para cambiar de modo, pulsa Detener.

La duplicación escala la imagen en GPU antes de codificarla. Mantiene el mismo
cliente, el descubrimiento automático, la validación previa de conexión y los
formatos de vídeo existentes. Los clientes anteriores conservan compatibilidad
mediante MPEG-TS. En este modo, el permiso UAC del panel solo prepara las reglas
de red; no arranca los brokers del driver.

Descargas y actualización:

- **WindowDeck-0.3.0-windows-x64.zip**: cierra la versión anterior, extrae el
  paquete completo en una carpeta nueva y abre `WindowDeck.exe`. Incluye
  FFmpeg/SDL, fuentes, licencias y manifiesto de hashes.
- **WindowDeck-0.3.0-steamdeck-x86_64.tar.gz**: extrae y ejecuta
  `bash install-steamdeck.sh` para instalar o actualizar el Flatpak y los accesos.
- **WindowDeck.flatpak**: alternativa para instalar con Discover o
  `flatpak install --user ./WindowDeck.flatpak`.
- **SHA256SUMS.txt**: hashes de las tres descargas.

Si ya tienes el cliente 0.2.2, puedes utilizar la nueva opción actualizando solo
Windows. No se requieren opciones nuevas en la Deck ni reinstalar el driver.
Los paquetes del cliente 0.3.0 se incluyen para instalaciones nuevas o para
mantener ambos extremos en la misma versión.

El funcionamiento de duplicación ha sido aceptado por el usuario. Las pruebas
locales verifican vídeo integrado/MPEG-TS, reconexión y parada sin auxiliar de
pantalla. **La mejora de latencia o de carga frente a extensión todavía no está
cuantificada**; no se garantiza una reducción por cambiar de modo.

Versión preliminar para Windows 11 y una LAN de confianza. Emparejamiento,
cifrado, entrada remota, instalación limpia y aceptación completa de la
codificación GPU del driver siguen pendientes. No se modifica el driver.
