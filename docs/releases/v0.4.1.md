WindowDeck 0.4.1 corrige detalles de la 0.4.0 y protege mejor la clave del PC.
Es compatible con 0.4.0: el protocolo y el emparejamiento no cambian.

- La clave privada de Windows se guarda cifrada con DPAPI para tu usuario. La
  clave de la 0.4.0 se cifra al primer arranque y conserva la misma identidad,
  así que no hay que volver a emparejar. Si vuelves a la 0.4.0 en Windows, esta
  no reconocerá el archivo nuevo: bórralo como indica el error y empareja de
  nuevo.
- Con una IP manual ya no hace falta `--native`:
  `flatpak run io.github.ik3rurru.WindowDeck IP_DEL_PC:48150 --fullscreen`
  funciona igual que el descubrimiento automático.
- Si el PC ya está transmitiendo a otro dispositivo, la Deck lo explica en vez
  de mostrar `Resource temporarily unavailable`.
- Nuevo `SECURITY.md` para reportar vulnerabilidades de forma privada y
  plantilla para reportar errores con los registros.
- [ADR 0023](../adr/0023-cpu-frame-ipc.md): la transferencia de frames por CPU
  pasa a ser la ruta definitiva del driver; la de texturas GPU queda como
  experimento.

Descargas:

- **WindowDeck-0.4.1-windows-x64.zip**: cierra WindowDeck, extrae el paquete
  completo en una carpeta nueva y abre `WindowDeck.exe`.
- **WindowDeck-0.4.1-steamdeck-x86_64.tar.gz**: extrae y ejecuta
  `bash install-steamdeck.sh` para actualizar Flatpak y accesos.
- **WindowDeck.flatpak**: instalación alternativa mediante Discover o
  `flatpak install --user ./WindowDeck.flatpak`.
- **SHA256SUMS.txt**: hashes de las tres descargas.

Pendientes: revocación en un uso real, escalas DPI 150/200 %, modo juego,
cancelar el UAC y medición física de latencia. El driver sigue con firma de
desarrollo. Versión preliminar para Windows 11 y LAN de confianza.
