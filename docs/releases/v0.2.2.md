WindowDeck 0.2.2 añade una validación previa de la conexión y corrige condiciones
que provocaban el ciclo de conexión/desconexión de la pantalla virtual.

**Actualiza Windows y Steam Deck a 0.2.2 para probar la validación completa.**

- La aplicación intercambia tráfico de prueba durante unos dos segundos antes
  de activar el monitor. Si la validación falla, muestra el problema y mantiene
  la pantalla desactivada.
- El reproductor integrado se inicializa antes de conectar. Los atascos breves
  disponen de más margen sin desmontar inmediatamente la pantalla.
- Los reintentos se espacian y tres fallos consecutivos de arranque pausan las
  activaciones. El panel indica cuándo comprobar la red y pulsar Detener/Iniciar.
- Los paquetes atrasados de una sesión ya no pueden cerrar la conexión nueva.
  Se conserva compatibilidad con versiones anteriores, aunque sin la prueba
  completa de tráfico cuando uno de los extremos es antiguo.

Descargas y actualización:

- **WindowDeck-0.2.2-windows-x64.zip**: cierra la versión anterior, extrae el
  paquete completo en una carpeta nueva y abre su `WindowDeck.exe`.
- **WindowDeck-0.2.2-steamdeck-x86_64.tar.gz**: cierra WindowDeck en la Deck,
  extrae el paquete y ejecuta `bash install-steamdeck.sh`. Actualiza el Flatpak
  y prepara los accesos de escritorio y Steam.
- **WindowDeck.flatpak**: alternativa para actualizar con Discover o
  `flatpak install --user ./WindowDeck.flatpak`.
- **SHA256SUMS.txt**: hashes de las tres descargas.

Para la prueba, inicia el host nuevo en Windows y abre el cliente nuevo en la
Deck. El panel debe pasar por la comprobación de estabilidad antes de activar
la pantalla y empezar a enviar vídeo. Si se pausan los reintentos, consulta
Ver registros antes de volver a pulsar Detener/Iniciar.

Las pruebas locales incluyen 55 pruebas Rust en cada configuración, tráfico
sintético, decodificación H.264, interrupción de fragmentos y reconexión. La
estabilidad en la red real y la sesión prolongada quedan pendientes de esta
prueba. Se mantiene el driver existente y el perfil CPU 1280 × 800 a 60 Hz.

Versión preliminar: requiere el driver de prueba ya instalado en Windows.
Emparejamiento, cifrado, entrada remota y aceptación completa de la ruta GPU
siguen pendientes.
