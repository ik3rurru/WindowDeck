WindowDeck 0.2.1 incorpora el lanzador Rust de Windows y el reproductor integrado
de la Steam Deck. La ruta CPU H.264 permite extender el escritorio a 1280 × 800;
al detener la sesión se retira el monitor virtual y se recuperan las ventanas.

Descargas:

- **WindowDeck-0.2.1-windows-x64.zip**: descomprime todo y abre `WindowDeck.exe`.
  Incluye host, auxiliar, FFmpeg/SDL, fuentes, licencias y manifiesto de hashes.
- **WindowDeck-0.2.1-steamdeck-x86_64.tar.gz**: extrae todo y ejecuta
  `bash install-steamdeck.sh`. Instala el Flatpak, crea el acceso del escritorio
  y deja `~/.local/bin/windowdeck` para añadirlo a Steam como producto externo.
- **WindowDeck.flatpak**: instalación directa con Discover o
  `flatpak install --user ./WindowDeck.flatpak`; crea la entrada del menú.
- **SHA256SUMS.txt**: hashes de las tres descargas.

El instalador de la Deck necesita Internet para obtener el runtime si falta.
El acceso de Steam ejecuta el cliente Linux, sin forzar Proton. Flatpak permite
añadir la aplicación al modo juego; AppImage queda como posible formato portátil.

Se han aceptado vídeo CPU, latencia y recuperación de ventanas en la Deck, con
reconexión y recogida de procesos después de un cierre inesperado del panel.
La integración visual en modo juego aún necesita una sesión real de aceptación.

Esta es una versión preliminar: requiere el driver de prueba ya instalado en
Windows y una LAN de confianza. El paquete no instala ni firma el driver.
Faltan emparejamiento y cifrado, entrada remota, instalación limpia, sesión
prolongada y aceptación completa de la ruta GPU. Las comprobaciones automáticas
de empaquetado no sustituyen esas pruebas.
